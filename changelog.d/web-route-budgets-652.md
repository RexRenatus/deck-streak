### Added

- Each route of the Mini App has a JavaScript budget, with a ratchet. After the web build, CI's web job reads the client build's manifest and gives each route the JavaScript its page and layouts import statically beyond the shell every route loads first, each file measured by `gzip -9 -n` and summed, and compares each figure with the route's entry in `config/web-route-budgets.json`. It reports a route over its entry, a route with no entry, an entry for a route that is gone, and a route more than 1024 bytes under its entry, whose entry the ratchet asks lowered. It starts at warn and moves to fail only by its own delivery; it prints how many routes it examined, and reads VOID, never a pass, when the build or the table cannot be read or holds no route (SPEC-652, ADR-674).
