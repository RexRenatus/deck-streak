### Added

- On iPhone and iPad the app opens an Anki deck package from the Files app through the system
  file importer and imports its notes and cards into the local collection through one engine
  call the engine allow-list admits, and the empty deck list offers the import. A package the
  app refuses, one with an inner member that decompresses past the bound included, reads as a
  worded error and writes no row (SPEC-681, ADR-703).
